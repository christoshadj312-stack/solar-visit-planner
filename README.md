# SolarVisit

A full-stack field visit and appointment management platform designed for solar sales and technical teams.

SolarVisit helps field engineers organize customer appointments, optimize routes, automate customer communication, track visit outcomes, and manage field operations from a single application.

## Highlights

- Appointment and customer management
- Calendar-based visit planning
- Route optimization and geocoding
- Automated SMS workflows
- GPS-based arrival notifications
- Android companion application for SMS automation
- Customer status tracking
- Reports and operational summaries
- Supabase authentication and database
- Responsive React interface

## Tech Stack

- React 18
- Vite
- Supabase
- JavaScript
- Kotlin / Android
- Vercel serverless functions
- Google Maps integrations

## Configuration

This public portfolio repository does not contain production credentials or customer data.

Copy the example environment file and provide your own development credentials:

```bash
cp .env.example .env
npm install
npm run dev
```

## Project Purpose

This project demonstrates the design and implementation of an end-to-end field operations platform, combining web development, backend services, location-based workflows, automation, and Android integration.
